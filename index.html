先记住三句话，再往下看图

  1. 在水里，这个说法站不住。严格控制的实验没做出可重复的效应，而且"温度计插深一点点"就能造出假象。水里：不支持
  2. 但在别的一些体系里，效应是真的。胶体颗粒、单个离子量子比特、颗粒气体、自旋玻璃等体系都做出来了，而且有的还是"指数级"加速。其它体系：支持
  3. 它不是"越热越快"。真正起作用的是"起点落在哪条通道上"，条件不对时效应会消失，甚至反过来。条件性极强

术语小词典（高中版）

姆潘巴效应
初始温度更高的样品反而更快冷却/凝固到目标状态的现象。名字来自 1960 年代坦桑尼亚学生 Erasto Mpemba。
判据 / 终点线
你规定"算到达"的那一刻：到 0 °C、开始结冰、还是全部冻实。判据不同，结论可能不同。
潜热
温度不变、物态改变时吸收或放出的热。0 °C 的水结成 0 °C 的冰要放出大量热，因此这个阶段对初始温度不敏感。
对流
水受热后密度变化引起的流动。它让杯内温度不均匀，也是"测温高度"成为关键变量的原因。
超冷
水低于 0 °C 仍未结冰。结冰起始点受随机性与杂质影响，所以"开始结冰"这个判据重复性差。
平衡态 / 非平衡态
平衡态是系统最终稳定下来的状态；非平衡态是还在变化的状态。姆潘巴效应是纯粹的"非平衡"现象。
弛豫时间
系统回到平衡态所需的时间尺度。姆潘巴效应说的就是"更热起点的弛豫时间反而更短"。
慢模态（图中的"慢通道"）
把弛豫过程分解成若干"通道"，最慢的那条通常决定总时长。若初始状态恰好不踩这条通道，整体就快得多。
强姆潘巴 / 指数级加速
最慢通道的贡献为 0 时的特殊情形，弛豫时间突然跳变到更小值，表现为指数级更快的平衡（也就是图 ⑤ 里"直接走快道"）。
反向姆潘巴
反过来：初始更冷的系统更快升温到热末态（图 ⑦）。已在单个囚禁离子量子比特上实现。
瑞利数（Ra）
描述流体对流强弱的无量纲数。报告中水冷却数据在很大范围内与高瑞利数对流规律吻合。
预注册
动手之前就把判据、样本量、排除规则写下来，防止事后挑选结论（图 ⑧ 那块牌子）。
